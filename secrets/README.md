# secrets/

Production secrets consumed by `docker-compose.yml` as Docker secrets (mounted at `/run/secrets/<name>`).
Everything in this folder except this README is git-ignored. **Never commit real secret files.**

| File | Used by | Notes |
|------|---------|-------|
| `postgres_password.txt` | postgres, pgbackrest, api | Password for `POSTGRES_USER` |
| `redis_password.txt` | redis, api | Redis `requirepass` |
| `jwt_secret.txt` | api | HS256 signing key, at least 32 random characters |
| `rabbitmq_password.txt` | rabbitmq, api | Only for the optional `docker-compose.rabbitmq.yml` overlay (generated by `secrets-setup.sh`) |
| `dataprotection_cert.pfx` | api | Encrypts the Data Protection key ring at rest. Used by the `docker-compose.dataprotection.yml` overlay. `secrets-setup.sh` creates it only when missing; never replace it casually (see the wiki) |
| `dataprotection_cert_password.txt` | api | Password of the PFX (`Identity:DataProtection:Certificate:Password`) |

Create them with `deployment/secrets-setup.sh`, or manually:

```bash
openssl rand -base64 32 | tr -d '\n' > secrets/postgres_password.txt
openssl rand -base64 32 | tr -d '\n' > secrets/redis_password.txt
openssl rand -base64 48 | tr -d '\n' > secrets/jwt_secret.txt
openssl rand -base64 24 | tr -d '\n' > secrets/rabbitmq_password.txt   # only for the RabbitMQ overlay
chmod 600 secrets/*.txt

# Data Protection key encryption certificate (only if it does not exist yet)
openssl rand -base64 32 | tr -d '
' > secrets/dataprotection_cert_password.txt
openssl req -x509 -newkey rsa:3072 -sha256 -days 3650 -nodes -subj "/CN=StarterKit Data Protection" -keyout /tmp/dp.key -out /tmp/dp.crt
openssl pkcs12 -export -out secrets/dataprotection_cert.pfx -inkey /tmp/dp.key -in /tmp/dp.crt -passout file:secrets/dataprotection_cert_password.txt
rm /tmp/dp.key /tmp/dp.crt && chmod 600 secrets/dataprotection_cert.pfx
```

See `wiki/deployment/README.secrets.md` for details.
