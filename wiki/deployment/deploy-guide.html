Create Deploy User + Harden SSH
~8 min
▶
ⓘ
AWS EC2 defaults to SSH_USER. Best practice: create a dedicated DEPLOY_USER user, then disable root login.
SSH as ubuntu & create deploy user
ssh -i KEY_PATH SSH_USER@EC2_IP

# Create deploy user with sudo
sudo adduser --disabled-password --gecos "" DEPLOY_USER
sudo usermod -aG sudo DEPLOY_USER

# Allow sudo without password (needed for GitHub Actions runner)
echo "DEPLOY_USER ALL=(ALL) NOPASSWD:ALL" | sudo tee /etc/sudoers.d/DEPLOY_USER

# Copy SSH key to deploy user
sudo mkdir -p /home/DEPLOY_USER/.ssh
sudo cp ~/.ssh/authorized_keys /home/DEPLOY_USER/.ssh/
sudo chown -R DEPLOY_USER:DEPLOY_USER /home/DEPLOY_USER/.ssh
sudo chmod 700 /home/DEPLOY_USER/.ssh
sudo chmod 600 /home/DEPLOY_USER/.ssh/authorized_keys
Test deploy user login (new terminal)
ssh -i KEY_PATH DEPLOY_USER@EC2_IP
sudo whoami  # should print: root
Harden SSH (back in ubuntu session)
# Disable root login & password auth
sudo sed -i 's/#\?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -i 's/#\?PubkeyAuthentication.*/PubkeyAuthentication yes/' /etc/ssh/sshd_config
sudo sed -i 's/#\?MaxAuthTries.*/MaxAuthTries 3/' /etc/ssh/sshd_config

sudo systemctl restart ssh
⚠
Keep your ubuntu session open until you verify deploy user works. If locked out, use AWS EC2 Serial Console.
