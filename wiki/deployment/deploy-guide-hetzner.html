Hetzner Console — Create Server + SSH Key + Firewall
~10 min
▶
Generate SSH key pair (on your local machine)
ssh-keygen -t ed25519 -C "starterkit-hetzner" -f KEY_PATH
cat KEY_PATH.pub

Copy the public key output — you'll paste it in Hetzner Console.

Create Firewall in Hetzner Console

Go to: Hetzner Cloud Console → Firewalls → Create Firewall

ⓘ

Create Deploy User + Harden SSH
~8 min
▶
ⓘ
Hetzner defaults to root. Best practice: create a non-root deploy user, then disable root SSH.
SSH as root & create deploy user
ssh -i KEY_PATH root@SERVER_IP

# Create deploy user with sudo
adduser --disabled-password --gecos "" DEPLOY_USER
usermod -aG sudo DEPLOY_USER

# Allow sudo without password
echo "DEPLOY_USER ALL=(ALL) NOPASSWD:ALL" > /etc/sudoers.d/DEPLOY_USER

# Copy SSH key to deploy user
mkdir -p /home/DEPLOY_USER/.ssh
cp /root/.ssh/authorized_keys /home/DEPLOY_USER/.ssh/
chown -R DEPLOY_USER:DEPLOY_USER /home/DEPLOY_USER/.ssh
chmod 700 /home/DEPLOY_USER/.ssh
chmod 600 /home/DEPLOY_USER/.ssh/authorized_keys
Test deploy user login (new terminal)
ssh -i KEY_PATH DEPLOY_USER@SERVER_IP
sudo whoami  # should print: root
Harden SSH (as deploy user with sudo)
# Disable root login & password auth
sudo sed -i 's/#\?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -i 's/#\?PubkeyAuthentication.*/PubkeyAuthentication yes/' /etc/ssh/sshd_config
sudo sed -i 's/#\?MaxAuthTries.*/MaxAuthTries 3/' /etc/ssh/sshd_config

sudo systemctl restart ssh
⚠
Keep your root session open until you verify deploy user works. If you lock yourself out, use Hetzner Console rescue mode.

System Setup — Docker, Nginx, UFW, Tools
~15 min
▶

All commands below as DEPLOY_USER:

System update & timezone
ssh -i KEY_PATH DEPLOY_USER@SERVER_IP

sudo apt update && sudo apt upgrade -y
sudo timedatectl set-timezone TZ
sudo hostnamectl set-hostname HOSTNAME
Install Docker
sudo apt install -y apt-transport-https ca-certificates curl software-properties-common gnupg lsb-release
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker DEPLOY_USER
newgrp docker
docker --version && docker compose version
Install Nginx, Certbot & tools
sudo apt install -y nginx certbot python3-certbot-nginx git jq htop unzip openssl
UFW firewall (defense-in-depth alongside Hetzner FW)
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
sudo ufw status verbose

GitHub Self-Hosted Runner
~12 min
▶
Get token from GitHub → Settings → Actions → Runners → New
Install runner
mkdir -p ~/actions-runner && cd ~/actions-runner
curl -o actions-runner-linux-x64-2.322.0.tar.gz -L \
  https://github.com/actions/runner/releases/download/v2.322.0/actions-runner-linux-x64-2.322.0.tar.gz
tar xzf ./actions-runner-linux-x64-2.322.0.tar.gz

./config.sh --url GH_REPO \
  --token RUNNER_TOKEN \
  --name HOSTNAME-runner \
  --labels self-hosted,deploy-only \
  --work _work --runasservice

sudo ./svc.sh install && sudo ./svc.sh start && sudo ./svc.sh status
Verify Idle (green) in GitHub Settings

Post-Deploy Hardening
~5 min
▶
Auto security updates

sudo apt install -y fail2ban

Swap file (safety net for 8GB RAM)
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
