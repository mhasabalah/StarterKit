## Your next product starts here

A working foundation, with space for your domain. Install the template, create your project, and run the stack with Aspire.

<Steps>

1. **Install the templates.** First complete the <a href={`${siteBase}getting-started/templates/#install`}>GitHub Packages feed setup</a> outside any repository.

   ```bash
   dotnet new install StarterKit.Templates
   ```

2. **Create your product.** Start with the defaults, or choose the tenancy, transport, and storage options in the guide.

   ```bash
   dotnet new starterkit -n Acme
   ```

3. **Run with Aspire.** With the .NET 10 SDK and Docker available, launch the API and its backing services.

   ```bash
   cd Acme/src/Aspire/AppHost && dotnet run
   ```

</Steps>

Continue with the <a href={`${siteBase}getting-started/new-project/`}>configuration and verification checklist</a> before deployment.
